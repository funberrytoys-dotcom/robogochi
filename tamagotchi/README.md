# Робогочи · прототип тамагочи v0.1

Toysberry Game Studio · 12 ноября 2026

Робот-малыш живёт в телефоне. Его можно гладить, кормить, мыть, укладывать спать, поднимать, бросать ему мячик и играть с ним в две мини-игры. 20 роботов из концепции уже живут в этом движке.

- **Играть с телефона:** https://funberrytoys-dotcom.github.io/robogochi/play/ (открытая ссылка) или https://claude.ai/artifact/BPjiN6bZLybDZxrqAkbrRy (приватная; чтобы показать другим, открой её и нажми Share).
- **Видео со звуком:** https://funberrytoys-dotcom.github.io/robogochi/video/robogochi-demo.mp4, записывается командой `node tools/film.mjs`.
- **Android:** [builds/robogochi-0.1.0.apk](builds/robogochi-0.1.0.apk), 0,26 МБ, на GitHub лежит в [релизах](https://github.com/funberrytoys-dotcom/robogochi/releases/latest). Установка: `adb install -r builds/robogochi-0.1.0.apk` или скопировать на телефон. Проверено на эмуляторе Android 16 (API 36).
- **Без интернета:** [dist/robogochie.html](dist/robogochie.html) открывается в любом браузере. На компьютере игра показывается вертикальным «телефоном» по центру.
- **Концепция:** https://claude.ai/artifact/Dj92pC8u5wNQAPaeUt3oBW, исходник [../concept-claude/index.html](../concept-claude/index.html).

## Что делать в игре

| Жест | Что делает робот |
| --- | --- |
| Провести пальцем по голове | Жмурится, урчит, наклоняется к пальцу, летят сердечки |
| Тыкнуть в голову | Удивляется, переспрашивает «пип?», прыгает или делает свой трюк |
| Тыкнуть в пузико | Хихикает от щекотки |
| Тыкнуть 5 раз подряд | Падает набок или плюхается на попу, кружится голова, встаёт |
| Потянуть за пузико (или долго держать голову) | Поднимается, болтает ножками; отпустить — падает и приземляется |
| Постучать по стеклу 2–4 раза | Подходит и отвечает клювом тем же ритмом |
| «Еда» → перетащить печеньку к клюву | Открывает клюв, хрустит, иногда рыгает. Бросишь на пол — сам подберёт |
| «Мыть» → тереть губкой | Пена, хихиканье, потом душ и отряхивание |
| «Спать» | Идёт в док, зевает, спит и заряжается. Свет гаснет. «Разбудить» или тап по роботу будит |
| «Игры» | «Лови винтики», «Пи-пи-повтори», «Танцы», «Мячик» |
| «Магазин» | Шапки (пропеллер умеет летать) и мебель: коврик, ночник, цветок, постер, проектор звёзд |
| «Роботы» | Коллекция из 20: условия открытия, прогресс, премиум-наборы с кнопкой «Примерить» |

Для показа: шестерёнка вверху → «Демо: открыть всех 20 роботов» и «Демо: +100 винтиков». Там же «Начать заново».

## Как устроено

Один HTML-файл на 277 КБ, без библиотек и без звуковых файлов.

- `src/draw_robot.js` — 2D-риг робота кодом: 7 форм головы, экран-лицо с 12 выражениями, утиный клюв, антенны и шапки, ноги на обратной кинематике. Робот описан данными в `src/robots.js`, поэтому новый робот — это новая строка, а не новая графика.
- `src/robot.js` — «мозг»: ноги переступают и стоят на полу, корпус качается при шаге, голова и антенна догоняют на пружинах, взгляд следит за пальцем, моргание.
- `src/behaviors.js` — сценки: привет, прыжки, кружение, падение и подъём, еда, мытьё, сон, ответ на стук, мячик, фирменный трюк каждого робота.
- `src/audio.js` — синтез писка: у каждого робота свой тембр и высота. Музыка в танцах и мини-играх временная, синтезированная.
- `src/room.js` — убежище, мебель, мячик, жесты. `src/ui.js` — кнопки и панели. `src/games.js` — мини-игры. `src/main.js` — заставка, выбор, потребности, сохранение.

Сохранение лежит в localStorage браузера. Потребности убывают в реальном времени, но после долгого отсутствия не падают ниже 22 из 100: робот не умирает и не портится, а встречает подарком.

## Сборка

```bash
cd tamagotchi
node build.mjs
python tools/build_android.py 0.1.0
```

`build.mjs` собирает `dist/robogochie.html` (для телефона и APK) и `dist/artifact.html` (для ссылки). `build_android.py` собирает APK без Gradle в ASCII-папке `Playground/_rg_android/`. Ключ подписи создан в `android/keystore/`: если игра пойдёт в Google Play, его надо сохранить в надёжном месте.

Проверки без окон: `node tools/play.mjs <шаги.json> <папка>` гоняет сценарий в безголовом Chrome с размером экрана телефона и снимает скриншоты, `node tools/snap.mjs tools/lineup.html out.png 1600 1500` рисует постер всех роботов.

## Что проверено и что нет

- Проверено в безголовом Chrome 390×844 и 768×1024: заставка, выбор и имя, поглаживание, падение и подъём, стук, кормление, мытьё, сон и пробуждение, подъём робота, магазин, мебель, коллекция, обе мини-игры, танцы, ночь со звёздами. Ошибок в консоли нет.
- APK установлен и запущен на эмуляторе: заставка, глаза, комната. На эмуляторе не загрузился шрифт Nunito из Google Fonts (ошибка сертификата в эмуляторе), игра переключилась на системный шрифт. Без интернета будет так же.
- На живом телефоне не проверено. Звук в безголовом режиме не прослушан, только сгенерирован.
- Музыка — временная заглушка. Промпты для Suno: [MUSIC-PROMPTS.md](MUSIC-PROMPTS.md).
