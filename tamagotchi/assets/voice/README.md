# Голосовые карточки

Четырнадцать коротких реплик подготовлены локально для Робогочи. Исходный синтез — Piper 1.8.0, русский голос Denis medium. Согласно [карточке модели](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/denis/medium/MODEL_CARD), речевой корпус и корпус базовой модели опубликованы под CC0. Подняты тон и темп, добавлен лёгкий хорус. В игру входят только готовые MP3, 24 кГц, моно.

`a`, `o`, `u` — гласные. `ma`, `mu`, `pa` — слоги. `mama`, `nyam`, `privet`, `ura`, `myach`, `bayu`, `chisto`, `poka` — слова. Идентификаторы используются в памяти питомца и при встраивании звука в HTML.
